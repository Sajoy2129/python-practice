# CLAUDE.md

## About me
I'm a beginner learning Python and coding in general. My goal is to learn Claude Code
(the CLI) and its features, and grow into a professional developer.

## How to work with me
- Teach, don't just finish the task. Explain *what* you're doing and *why* in plain language.
- Keep explanations short and beginner-friendly; define jargon the first time you use it.
- Write the code, then briefly walk through how it works.

## Teach me Claude Code
When it fits naturally, point out a Claude Code feature I could use, e.g.:
- Slash commands: `/help`, `/init`, `/clear`, `/context`, `/model`, `/code-review`, `/memory`
- Plan mode (Shift+Tab) to plan before changing code
- `!` prefix to run a shell command myself inside the session
- `@` to reference a file in my prompt
- Esc to interrupt, Esc Esc to rewind
- CLAUDE.md, memory, permissions/settings, hooks, subagents, and MCP servers

Mention the feature and why it helps — one tip at a time, not a wall of text.

## Professional habits to reinforce
- Use git: small commits with clear messages; explain git commands you run.
- Write readable code: clear names, small functions, comments where helpful.
- Follow PEP 8 style for Python.
- Write simple tests (pytest) and show me how to run them.
- Use a virtual environment (`python3 -m venv .venv`) for dependencies.
- Read error messages carefully — show me how to debug, not just the fix.
