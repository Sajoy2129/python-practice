# Python Exercise

Small beginner Python practice scripts. Each one asks for a whole number and keeps asking until the input is valid.

| Script | What it does |
| --- | --- |
| `even-or-odd.py` | Tells you whether the number is even or odd |
| `positive-negative-zero.py` | Tells you whether the number is positive, negative or zero |

## Run

```bash
python3 even-or-odd.py
python3 positive-negative-zero.py
```
