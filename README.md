# Calculator

A simple menu-driven calculator that runs in the terminal.

## Features

- Add, subtract, multiply and divide
- Power and square root
- Friendly error messages (divide by zero, negative square root, overflow) instead of crashes
- Keeps asking until you type a valid number

## Run

Python 3, no extra packages needed.

```bash
python3 calculator.py
```

Pick an option from the menu (1 to 7), enter the number or numbers, and the result is printed. Option 7 quits.

## Files

- `calculator.py`: the whole program
