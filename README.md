# Python Practice

Small projects I built while learning Python, Git and web basics, collected in one place.
Each folder used to be its own repository. They were merged here with their full commit
history, using `git subtree`.

## Projects

| Folder | What it is | How to run |
| --- | --- | --- |
| [calculator](calculator/) | Menu-driven terminal calculator (add, subtract, multiply, divide) | `python3 calculator/calculator.py` |
| [guess-game](guess-game/) | Guess the secret number from 1 to 100 with "too high / too low" hints | `python3 guess-game/guess.py` |
| [tip-splitter](tip-splitter/) | Splits a restaurant bill, tip included, between people | `python3 tip-splitter/tip.py` |
| [todo-list](todo-list/) | Terminal to-do list that saves your tasks between runs | `python3 todo-list/todo.py` |
| [Python-Exercise](Python-Exercise/) | Beginner scripts: even-or-odd and positive/negative/zero | `python3 Python-Exercise/even-or-odd.py` |
| [learning_github](learning_github/) | Notes from practicing Git and GitHub (no code) | n/a |
| [web/hello](web/hello/) | First HTML practice page | Open `web/hello/hello.html` in a browser |
| [web/hello_there](web/hello_there/) | Second HTML practice page | Open `web/hello_there/hello_there.html` in a browser |

All Python projects use only the standard library, so there's nothing to install.
