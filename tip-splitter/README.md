# Tip Splitter

A tiny terminal program that splits a restaurant bill, tip included, between any number of people.

## Run

```bash
python3 tip.py
```

It asks for:

1. Bill amount
2. Tip percentage
3. Number of people

Then it prints what each person pays, rounded to 2 decimal places.

Example: a bill of 100 with a 10% tip split between 4 people gives 27.5 each.

## Files

- `tip.py`: the whole program
